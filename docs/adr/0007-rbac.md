# ADR 0007 — RBAC, deny by default, audit

- **Holat:** Qabul qilingan · 2026-11-11 (T-008)

## Qaror

1. **Uch dekorator, bittasi majburiy:** `@Public()` · `@Authenticated()` (faqat o'z ma'lumoti) ·
   `@RequirePermission(...)` (barchasi kerak). Global guard'lar tartibi: `AccessTokenGuard` →
   `PermissionsGuard`. Dekoratorsiz endpoint — runtime'da 403 va CI'da yiqiladi
   (`apps/api/src/access-rules.test.ts`).
2. **Samarali ruxsat** = faol rol matritsasi (`@lg/contracts` `ROLE_PERMISSIONS`) ± override'lar
   (`user_permission_overrides`), `@lg/domain` `effectivePermissions()`. Rollar birlashtirilmaydi.
   Kesh — Redis `perm:{user}:{role}:{pv}`; har o'zgarish `permissions_version + 1` → eski kesh va
   eski tokenlar avtomatik yaroqsiz.
3. **Override qoidasi:** `granted=true` — faqat Admin'ga va faqat `DELEGABLE_PERMISSIONS`;
   delegatsiya qilinmaydigan — 422 `NON_DELEGABLE_PERMISSION`; `granted=false` — cheklash.
4. **Faol rol** sessiyada (`sessions.active_role`); almashtirilsa eski rolli token yaroqsiz.
5. **Oxirgi faol Director** — bloklash/rolni olish 409 `LAST_DIRECTOR` (qatorlar qulf bilan).
6. **Audit:** yozish endpoint'i `@Audit({action, entity})` (interceptor: `after` = javob, sirlar
   yashirilgan) yoki `@NoAudit('sabab')` (service ichida before/after bilan) — CI tekshiradi.
7. **Hujjat = kod:** `roles.test.ts` 02 §4 jadvalini o'qib `ROLE_PERMISSIONS` bilan solishtiradi.
8. **Policy'lar** — `packages/domain/policies`, sof funksiyalar, Toshkent kalendari.
9. **Scope** (o'z obyekti) — service qatlamida, o'z jadvallari bilan (T-103/T-104/T-105).
