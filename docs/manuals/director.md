# Direktor uchun yoʻriqnoma

> Kimga: markaz Direktori. Shakl: "Qanday qilaman?" — savol va qadamlar. Tugma va menyu nomlari
> ekrandagi bilan bir xil. Yangilangan: 2026-11-16 (T-506, T-121, T-122).

Tizim uch joyda ishlaydi:

| Qayerda                          | Nima uchun                                                           |
| -------------------------------- | -------------------------------------------------------------------- |
| **Web panel** (kompyuter)        | Hamma narsa: oʻquvchilar, guruhlar, toʻlovlar, xodimlar, hisobotlar  |
| **Mini App** (Telegram, telefon) | Tezkor ish: bugungi koʻrsatkichlar, chek navbati, soʻrovlar, qidiruv |
| **Bot** (Telegram chat)          | Xabarlar: kirishni tasdiqlash, soʻrovlar, ogohlantirishlar           |

Web panel manzili: **https://app.legendary-academy.uz**

---

## 1. Kirish

### Web panelga qanday kiraman?

Eng oson yoʻl — **Mini App orqali** (telefon raqam, parol, kod kerak emas):

1. Telegramda markaz botini oching → pastdagi **menyu tugmasi** bilan Mini App'ni oching.
2. **«Bugun»** ekrani pastidagi koʻk **«Boshqaruv panelini ochish»** tugmasini bosing.
3. Panel brauzerda ochiladi — tayyor.

Havola bir martalik va 60 soniya amal qiladi: har safar tugmani qayta bosing, havolani
birovga yubormang.

**Kompyuterda parol bilan:**

1. https://app.legendary-academy.uz → **Telefon raqam** maydonida `+998` yozilgan — faqat qolgan
   9 raqamni kiriting (masalan `500090450`).
2. **Parol** → **«Kirish»**.
3. Shu zahoti botdan **«🔐 Boshqaruv paneliga kirish»** xabari keladi → **«✅ Tasdiqlash»** ni
   bosing. Panel oʻzi ochiladi.
   - Yoki Google Authenticator'dagi 6 xonali kodni kiriting — qaysi biri qulay.

**Parolsiz, faqat Telegram bilan:** kirish sahifasida telefon raqamni kiriting →
**«Telegram orqali kirish»** → botdagi **«✅ Tasdiqlash»**.

### Kira olmayapman — nima qilay?

| Xabar                                | Sabab va yechim                                                                                                                             |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| «Telefon raqam yoki parol notoʻgʻri» | Raqamni tekshiring: `+998` dan keyin 9 ta raqam, boʻshliqsiz. Raqam toʻgʻri boʻlsa — parol xato.                                            |
| «Tasdiqlash kodi notoʻgʻri»          | Authenticator'da **eski** "Legendary Group" yozuvi qolgan. Hammasini oʻchirib, QR'ni qayta skanerlang. Yoki botdagi «Tasdiqlash» ni bosing. |
| Botdan xabar kelmadi                 | Telegram akkauntingiz ulanmagan boʻlishi mumkin — pastdagi "Telegramni ulash" ga qarang.                                                    |
| Parolni unutdim                      | Mini App → «Boshqaruv panelini ochish» bilan kiring. Yangi parol uchun texnik masʼulga murojaat.                                            |

### Telegramni qanday ulayman?

Web panel → **Bosh sahifa** → **«Telegramni ulash»** → **«Ulash havolasini olish»** →
**«Botni ochish va ulash»** → botda **Start** → raqamingizni ulashing. Havola 24 soat, bir marta.

### Boshqa qurilmalardan chiqish

Menyu → **Mening sessiyalarim** → kerakli qurilmada **«Chiqish»** yoki
**«Barcha qurilmalardan chiqish»**.

---

## 2. Xodimlar

### Administrator yoki ustoz qanday qoʻshaman?

1. Menyu → **Xodimlar** → **«Xodim qoʻshish»**.
2. **F.I.Sh**, **Telefon raqam**, **Rol** (Admin yoki Ustoz) → **«Qoʻshish va taklif qilish»**.
3. **Taklif havolasi** chiqadi — **«Nusxalash»** bosing va xodimga yuboring. Havola faqat hozir
   koʻrsatiladi.
   - **Admin**: havola orqali parol oʻrnatadi va kompyuterdan kiradi.
   - **Ustoz**: havolani Telegramda ochadi, raqamini ulashadi — Mini App'da darslari chiqadi.

Havola yoʻqolsa yoki muddati oʻtsa: xodim kartasi → **«Taklifni qayta yuborish»**.

### Oʻzim ham dars bersam?

Menyu → **Xodimlar** → oʻzingizni tanlang → **«Ustoz rolini qoʻshish»**. Keyin oʻzingizni
guruhga ustoz qilib biriktiring (4-boʻlim). Mini App ochilganda **Direktor** yoki **Ustoz**
rejimini tanlaysiz; rejimlar aralashmaydi, almashtirish — bir tegish.

### Xodim ishdan ketsa?

Xodim kartasi → **«Bloklash»**. Barcha qurilmalardagi sessiyalari darhol yopiladi.
Qaytarish — **«Blokdan chiqarish»**. Rolni olish — **«… rolini olish»**.

---

## 3. Kurslar va xonalar

Menyu → **Kurslar va xonalar** → **«Yangi kurs»** (nomi, oylik narx, dars davomiyligi) yoki
**«Yangi xona»** (raqami, sigʻimi). Keraksiz kurs — arxivlanadi (yangi guruhlarda chiqmaydi).

---

## 4. Guruhlar

### Yangi guruh

Menyu → **Guruhlar** → **«Yangi guruh»** → kurs, xona, kunlar va vaqt (**«Boshqa vaqt qoʻshish»**
— turli vaqtlar boʻlsa) → **«Guruh yaratish»**. Xona band boʻlsa — "Toʻqnashuv" ogohlantirishi
chiqadi.

### Ustoz biriktirish

Guruh → **Ustozlar** → **«Ustoz biriktirish»** → ustoz, **Vazifasi** (Asosiy / Yordamchi),
**Qaysi sanadan**. Yangi asosiy ustoz qoʻyilsa, eskisi oʻzi yakunlanadi.

### Jadvalni oʻzgartirish

Guruh → **«Jadvalni oʻzgartirish»** → **Qaysi sanadan**. Oʻtgan darslar oʻzgarmaydi.

### Bayram kunlari

Menyu → **Sozlamalar** → **Bayramlar** → sana, nom → **«Qoʻshish»**. Bu kunlardagi darslar
avtomatik bekor boʻladi.

---

## 5. Oʻquvchilar

### Yangi oʻquvchi va guruhga yozish

1. Menyu → **Oʻquvchilar** → **«Yangi oʻquvchi»** → maʼlumotlar (ota-onani keyin ham qoʻshish
   mumkin) → **«Oʻquvchi qoʻshish»**.
   **Oʻquvchi raqami** — oʻzingiz bergan raqam (masalan `1325`): titul varaqda va Excel bilan
   test natijalarini yuklashda shu raqam ishlatiladi. Boʻsh qoldirsangiz, tizim oʻzi beradi.
   Raqam band boʻlsa, tizim aytadi — boshqasini kiriting. Keyin kartadan tahrirlash mumkin.
2. Oʻquvchi kartasi → **«Guruhga yozish»** → guruh, **Qaysi sanadan** → **«Yozish»**.

### Ota-onani botga ulash

Kartada **«Ota-ona qoʻshish»** — telefon raqami bilan. Ota-ona botda Start bosib, xuddi shu
raqamni ulashsa — avtomatik bogʻlanadi. Raqam mos kelmasa, soʻrov **Bogʻlanish soʻrovlari**
boʻlimiga tushadi — u yerda tasdiqlaysiz yoki rad etasiz.

### Oʻquvchiga Mini App kodi berish

Oʻquvchi Telegram bot va Mini App orqali oʻz dars jadvali, davomati va natijalarini koʻrishi uchun
shaxsiy kirish kodiga ega boʻlishi lozim:

1. Oʻquvchi kartasi (W-06) da **«Mini Appʼga kirish»** blokini oching.
2. Agar kod oʻrnatilmagan boʻlsa: **«Kod yaratish»** tugmasini bosing.
3. Agar kod ilgari oʻrnatilgan boʻlsa, lekin oʻquvchi uni yoʻqotgan boʻlsa: **«Kodni yangilash»**
   tugmasini bosing (tasdiqlash talab etiladi, eski kod oʻz kuchini yoʻqotadi).
4. Generatsiya qilingan 6 xonali maxfiy kod (masalan, `849201`) ekranda faqat **1 marta** koʻrsatiladi.
   Uni **«Nusxa olish»** orqali nusxalab, oʻquvchiga shaxsan topshiring. Tizimda kod faqat xeshlangan holda saqlanadi.
5. Oʻquvchi botga kirib (`/student` yoki "Men oʻquvchiman") ushbu kodni kiritgach, Telegram profilingiz
   oʻquvchi kartochkasiga birikadi va blokda status **«Bogʻlangan»** deb yangilanadi.
6. Agar oʻquvchining akkauntini oʻzgartirish yoki uzish kerak boʻlsa, **«Telegramdan uzish»**
   tugmasini bosing. Oʻquvchi arxivlanganda Telegram avtomatik tarzda uziladi.

### Boshqa guruhga koʻchirish, muzlatish, chiqarish

Oʻquvchi kartasi → guruh qatori:

- **«Boshqa guruhga koʻchirish»** — chegirma saqlanadi.
- **«Muzlatish»** — kamida 14 kun (masalan, kasallik); shu davr darslari keyingi oy hisobidan
  ayriladi.
- **«Guruhdan chiqarish»** — oxirgi kun va sabab bilan.

### Lidlar (qiziqqanlar)

Menyu → **Lidlar** → **«Lid qoʻshish»**. Kelib yozilsa — lid kartasidan **«Guruhga yozish»**.

---

## 6. Toʻlovlar

### Naqd yoki karta toʻlovini kiritish

Menyu → **Toʻlov kiritish** (istalgan sahifadan klaviaturada **Alt+P**) → oʻquvchi, summa, usul →
**«Saqlash va chek chiqarish (Enter)»**.

### Ota-ona oʻtkazma chekini yubordi

Menyu → **Chek navbati** (yoki Mini App → **Navbat**) → rasmni tekshiring → summani toʻgʻrilang
(chekdagi haqiqiy summa) → **Tasdiqlash** yoki **Rad etish** (sabab bilan). Ota-onaga botdan
natija boradi. 24 soatdan oshgan cheklar alohida belgilanadi.

### Qarzdorlar

Menyu → **Qarzdorlar** — muddat boʻyicha (0–7, 8–30, 30+ kun). **«Hozir eslatish»** —
ota-onaga botdan eslatma.

### Chegirma

Oʻquvchi kartasi → **«Chegirma berish»** yoki menyu → **Chegirmalar**. Admin oʻz limitidan
(Sozlamalar → **Admin chegirma limiti**) oshirsa — sizga soʻrov keladi.

### Toʻlovni bekor qilish (storno) yoki pulni qaytarish

Toʻlov sahifasi → **«Storno»** yoki qaytarish. Admin buni qilsa — sizga soʻrov keladi.

### Kunlik kassa

Menyu → **Kassa** → **Sanalgan naqd** ni kiriting → farq boʻlsa, sababini yozing →
**«Kunni yopish»**.

---

## 7. Tasdiqlash soʻrovlari

Admin'ning chegirma, storno, qaytarish yoki davomatni tahrirlash soʻrovlari sizga keladi:
botda xabar + **Mini App → Soʻrovlar** yoki web → **Tasdiqlash soʻrovlari**. Tasdiqlansa, amal
darhol bajariladi. 48 soat javobsiz qolsa — soʻrov oʻzi bekor boʻladi.

---

## 8. Ustozlar oyligi

1. Menyu → **Oyliklar hisobi** → **Hisob oyi** ni tanlang → **«Hisoblash»**.
2. Har ustoz qatori → **«Tafsilot»**: bonus, jarima, **«Avans berish»**.
3. Tekshirgach → **«Tasdiqlash»** (faqat Direktor). Tasdiqlangan hisob qayta hisoblanmaydi.
4. Pul berilgach → **«Toʻlandi deb belgilash»**.

> ⚠️ **Ustoz shartnomasi** (fiks / foiz / aralash / darsbay) web panelda hali kiritib
> boʻlmaydi — texnik masʼulga ayting. Shartnomasiz ustozga oylik hisoblanmaydi.

## 10. Xabarlar

- **Ommaviy eʼlon** (barcha ota-onalar yoki guruhga): **Eʼlonlar** → **«Yangi eʼlon»** →
  **«Yuborish»**.
- **Ota-ona murojaatlari**: **Murojaatlar** → javob yozing → **«Javob yuborish»**.
- **Yetib bormagan xabarlar** (ota-ona botni bloklagan va h.k.): shu nomli boʻlim →
  **«Qayta yuborish»**.

---

## 11. Sozlamalar

Menyu → **Sozlamalar**:

- **Markaz** — nom, telefon, manzil.
- **Toʻlov** — karta raqami va egasi (ota-onalar shunga oʻtkazadi), **Toʻlov muddati**
  (oyning kuni), **Admin chegirma limiti**.
- **Davomat** — kech qolish chegarasi, ustozga eslatma vaqti.
- **Bayramlar**.

---

## Yordam

Yoʻriqnomada yoʻq savol yoki xato boʻlsa — texnik masʼulga: nima qildingiz, qaysi sahifada,
ekrandagi xabar (skrinshot bilan).
